# 小猪存钱罐 🐷

一款**纯本地、无广告**的可爱记账 PWA（渐进式网页应用）。数据只存在你自己的手机里，不联网、不上传任何服务器，隐私天然有保障。

蜜桃粉的软萌界面，支持多主题配色，记一笔就能把花出去的钱、存下来的钱、借出去的钱都理得清清楚楚。

---

## ✨ 功能一览

| 模块 | 说明 |
| --- | --- |
| 🏠 **今天** | 每日问候、本月结余 / 收入 / 支出、今日流水（含备注，点一下可删除） |
| 🐷 **存钱看板** | 首页会动的小猪：记收入投币、记支出叹气、点击随机互动（跳跳/摇摇/转圈）、达成目标撒金币庆祝；存款进度与本月预算进度一目了然 |
| ✏️ **记一笔** | 支出 / 收入切换，支持加减乘除表达式（如 `3×15`），emoji 分类、多账户、备注、日期 |
| 📊 **统计** | 按月 / 收支切换，分类占比甜甜圈图（随主题变色）、分类排行、**每日明细**（按天分组、可展开、可编辑） |
| 🎯 **目标** | 当前总存款（可校准）、月度消费阈值、年度存款目标（自定义起止日期）、**别人欠我**（借出 / 还款自动联动） |
| ⚙️ **我的** | 昵称、账户管理（支付宝 / 微信 / 银行卡 / 基金）、分类管理、主题颜色（7 种）、数据备份 |
| 🔔 **预算提醒** | 打开 App 时，若当月花费超过阈值的 80% / 100%，会温柔地提醒你 |
| 📖 **帮助文档** | 内置完整功能介绍，快速上手 |

### 主题配色 🎨
蜜桃粉 · 香芋紫 · 天空蓝 · 暖阳黄 · 薄荷绿 · 简约白 · 暗夜黑，统计图表配色会跟着主题一起变。

### 数据安全 🔒
- 所有数据通过浏览器 `localStorage` 存在**你自己的设备**上，**不上传任何服务器**。
- 换手机、清浏览器、卸载前，请务必在「我的 → 导出备份」留档，必要时用「导入备份」恢复。
- 备份文件是 `.json`，可自己留档。

## 📱 在 iPhone 上使用

1. 用 **Safari** 打开本应用部署后的网址（见下方「部署」）。
2. 点底部工具栏的**分享按钮**（一个方框加向上箭头 ⬆️）。
3. 在菜单里滑动找到并点 **「添加到主屏幕」**。
4. 确认名称后点「添加」。

完成后，主屏幕上会出现 App 图标，点开就是**全屏、无地址栏**的原生体验，没网也能打开。

> ⚠️ 注意：一定要用 **Safari** 打开并「添加到主屏幕」，不能直接在微信 / 其他浏览器里操作。

## 🤖 在安卓手机上使用

1. **首选 Chrome**（或 Edge）打开部署后的网址，点右上角**菜单（⋮）**，再点 **「安装应用」** 或 **「添加到主屏幕」**。

> ⚠️ **关于国产自带浏览器（vivo / 小米 / 华为 / OPPO / 荣耀等）**：它们的「添加到主屏幕」往往只是生成一个**普通网页快捷方式**，不支持真正的 PWA 安装——点开仍是带地址栏的浏览器样式，也不能离线。夸克浏览器同理。
>
> 因此**推荐安装一个 Chrome** 来添加。若你坚持用自带浏览器，请按下面的「两分钟验证法」确认是否装对。

### 两分钟验证法 ✅

1. 点图标打开，看**顶部有没有地址栏**——没有才是真正的 App；
2. 打开**飞行模式**（断网）再点图标，看**还能不能正常打开**——能开才说明离线缓存生效了。

只要这两点任一不满足，就说明装成的是「假快捷方式」，请换 **Chrome** 重新添加。

部分安卓机的 Chrome 菜单里可能显示「添加到主屏幕」而非「安装」，效果一样，都会在桌面生成图标、全屏运行、支持离线。

## 🚀 部署（把文件放到一个网址上）

App 是纯静态文件，放到任意静态托管即可。最推荐两个免费方案：

### 方式 A：GitHub Pages（免费，推荐）

1. 注册 GitHub，新建一个仓库（例如 `huajian-zhang`）。
2. 把本仓库所有文件上传到仓库根目录。
3. 仓库 → **Settings → Pages** → Source 选 `main` 分支 → **Save**。
4. 等一分钟，会得到一个网址，形如 `https://你的用户名.github.io/huajian-zhang/`。
5. 用这个网址按上面的 iPhone / 安卓步骤安装即可。

### 方式 B：Netlify（更简单，拖拽即用）

1. 打开 netlify.com，注册登录。
2. 把整个文件夹拖到首页的部署区域。
3. 几秒后得到一个网址，同样「添加到主屏幕」。

## 📁 文件清单

| 文件 | 作用 |
| --- | --- |
| `index.html` | 应用本体（浏览器打开即可用） |
| `sw.js` | 离线缓存（Service Worker，网络优先策略） |

## 🔄 更新说明

每次功能更新会同步提升版本号（见「我的 → App Author」一行），并在首次打开时弹出更新说明，之后不再重复显示。

> iOS 的 PWA 缓存刷新偶尔不稳定，若网页已更新但主屏 App 还是旧版，请**彻底杀掉 App（上滑关闭）后重开 2~3 次**，一般即可刷到最新版。
